Archivos Publisher grandes

Cómo convertir cientos o miles de archivos Publisher a PDF

Si tienes una carpeta llena de archivos de Microsoft Publisher, no deberías tener que abrir y exportar cada .pub manualmente.

Volver al inicio

Cuando convertir uno por uno ya no tiene sentido

Con 2 o 3 archivos Publisher, exportar manualmente puede estar bien. Con 20 archivos ya se vuelve repetitivo. Con 200 archivos puedes perder toda una tarde. Con 2,000 archivos, la tarea se convierte en un proyecto enorme.

Save Your PUB Files está pensado para usuarios normales de Windows que quieren convertir muchos archivos Publisher sin scripts, sin PowerShell y sin usar la línea de comandos.

Convertir muchos archivos a la vez

Seleccionas los archivos PUB o la carpeta, eliges dónde guardar los PDF y ejecutas la conversión. Save Your PUB Files usa Microsoft Publisher instalado en tu PC Windows para crear las copias en PDF.

Sirve para 20 archivos, 200 archivos o una carpeta grande con 2,000 archivos Publisher, siempre que Publisher pueda abrirlos.

Para usuarios de Windows, no para desarrolladores

La aplicación no sustituye a Microsoft Publisher y no abre archivos PUB sin Publisher. Lo que hace es evitar el trabajo repetitivo de abrir, exportar, cerrar y volver a empezar.

Lecturas relacionadas

Si estás preparándote para el fin de Publisher, lee Microsoft Publisher termina en 2026. Para el problema de abrir archivos uno por uno, consulta convertir archivos Publisher sin abrirlos uno por uno.

FAQ

¿Cómo convertir varios archivos Publisher a PDF?

Selecciona los archivos o una carpeta y conviértelos en una sola ejecución con Save Your PUB Files.

¿Puedo convertir todos mis archivos PUB a la vez?

Sí, si Microsoft Publisher está instalado en Windows y puede abrir esos archivos.

¿Puedo convertir un lote de archivos PUB a PDF?

Sí. La aplicación está hecha para grupos de archivos, no solo para un documento suelto.
