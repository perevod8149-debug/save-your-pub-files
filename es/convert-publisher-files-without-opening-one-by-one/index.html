El flujo manual

Para un archivo, el proceso es claro:

Abrir archivo PUB -> exportar o guardar como PDF -> cerrar archivo -> repetir

Si quieres convertir todos tus archivos Publisher a PDF, hacerlo así se vuelve lento y fácil de interrumpir.

El flujo con Save Your PUB Files

Save Your PUB Files lo reduce a:

Seleccionar archivos -> elegir salida -> convertir

Así puedes convertir varios archivos Publisher a la vez, sin abrir cada archivo manualmente. Los documentos permanecen en tu PC Windows.

Qué significa convertir automáticamente

La aplicación no lee archivos Publisher sin Publisher. Necesita una instalación funcional de Microsoft Publisher. Automatiza la exportación para los archivos que Publisher puede abrir.

Es útil con 20, 200 o 2,000 archivos.
