Le travail manuel

Pour un seul fichier, le chemin est simple :

Ouvrir le fichier PUB -> exporter ou enregistrer en PDF -> fermer le fichier -> recommencer

Pour convertir tous vos fichiers Publisher en PDF, cette méthode devient vite fatigante.

Le flux avec Save Your PUB Files

Save Your PUB Files simplifie le travail :

Sélectionner les fichiers -> choisir la sortie -> convertir

Vous pouvez convertir plusieurs fichiers Publisher à la fois, sans les ouvrir un par un. Les documents restent sur votre PC Windows.

Ce que signifie automatique ici

L’application ne lit pas les fichiers Publisher sans Publisher. Une installation fonctionnelle de Microsoft Publisher est nécessaire. Elle automatise l’export pour les fichiers que Publisher peut ouvrir.

C’est pratique pour 20, 200 ou 2,000 fichiers.
