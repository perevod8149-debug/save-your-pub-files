Before contacting support

  • Check that you are using Windows.
  • Check that Microsoft Publisher is installed and opens normally.
  • Check that the specific PUB file can be opened manually in Publisher.
  • Check that you have write access to the selected output folder.

What to include

  • Save Your PUB Files version.
  • Windows version.
  • Microsoft Publisher version, if known.
  • The exact error or message shown.
  • Whether Publisher can open the file manually.

Confidential files

Do not send confidential PUB files unless specifically requested and you are comfortable sharing them.

Purchase and refund support

For website purchases, payments and eligible refunds are handled through Paddle as Merchant of Record. For Microsoft Store purchases, payment and refund handling is through Microsoft Store billing.

For purchase or refund questions, include the purchase channel, order email address if available, and any Paddle or Microsoft Store order information available to you.
