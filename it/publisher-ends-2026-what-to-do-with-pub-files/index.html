Cosa cambia il 1 ottobre 2026

Microsoft termina il supporto di Publisher il 1 ottobre 2026. I file resteranno sul computer, ma aprirli, modificarli o condividerli potrebbe diventare più difficile.

Se hai pochi file

Per pochi documenti, aprili in Microsoft Publisher ed esportali manualmente in PDF.

Se hai un grande archivio

Con decine, centinaia o migliaia di file Publisher, salvare tutto uno per uno diventa un lavoro lungo. Microsoft suggerisce PowerShell per molti file; Save Your PUB Files offre una normale interfaccia Windows.

Publisher resta necessario

Save Your PUB Files non sostituisce Microsoft Publisher e non apre file PUB senza Publisher.
