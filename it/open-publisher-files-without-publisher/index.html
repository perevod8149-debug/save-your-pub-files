Importante: cosa fa Save Your PUB Files

Save Your PUB Files non consente di aprire, visualizzare o modificare i file PUB e non sostituisce Microsoft Publisher. Microsoft Publisher deve essere installato e funzionante sul PC Windows.

L’applicazione è progettata per un compito specifico: convertire in PDF decine o centinaia di file Publisher tutti in una volta, invece di aprire e salvare ogni file uno per uno.

Si può aprire un file PUB senza Publisher?

A volte sì, ma dipende dal file e da cosa intendi per aprire. Alcuni strumenti di terze parti possono importare o visualizzare in anteprima alcuni file Publisher, ma compatibilità, precisione del layout, font, immagini e funzioni di modifica possono variare.

Se il documento è importante, non dare per scontato che uno strumento diverso da Publisher lo conservi perfettamente. Tieni i file PUB originali anche dopo aver creato copie PDF.

Se devi aprire solo uno o due file PUB

Per pochi file, verifica prima se puoi ancora usare un’installazione funzionante di Microsoft Publisher. In caso contrario, potresti dover provare una suite per ufficio compatibile, un servizio di conversione o chiedere a qualcuno che ha Publisher di esportare i file per te.

Questo è un problema di accesso manuale. Save Your PUB Files non è pensato per aprire un singolo file PUB senza Publisher.

Se devi modificare un file PUB

Modificare file Publisher è il caso più difficile. Il percorso più sicuro resta Microsoft Publisher, perché formato del file, layout, font, immagini e caselle di testo sono stati progettati per Publisher.

Se modifichi un file PUB in un altro strumento, controlla con attenzione il risultato prima di usarlo.

Perché conservare i file Publisher come copie PDF?

Per conservare una copia visualizzabile, il PDF è spesso pratico perché è più facile da aprire, stampare, condividere e mantenere accessibile su computer dove Publisher non è disponibile.

Non eliminare i file PUB originali dopo averli convertiti.

Un PDF conserva una versione visualizzabile della pubblicazione, ma non sostituisce il file sorgente Publisher modificabile.

Cosa fare prima della fine del supporto di Publisher?

Se Publisher è ancora installato, convertire i documenti Publisher in PDF mentre funziona ancora può ridurre il rischio di perdere l’accesso in futuro. Per maggiori dettagli, leggi cosa fare con i file Publisher prima della fine del supporto di Publisher.

  • Esegui il backup dei file PUB originali.
  • Individua i file che potrebbero richiedere modifiche in futuro.
  • Crea copie PDF dei documenti che servono soprattutto per visualizzazione, stampa, condivisione o consultazione.
  • Verifica un campione dei PDF convertiti.
  • Conserva sia i file PUB originali sia le copie PDF.

Hai molti file Publisher? È un problema diverso

Trovare un modo per aprire un file PUB non è la stessa cosa che conservare una cartella piena di vecchi documenti Publisher. Quando hai decine o centinaia di file, il problema diventa il lavoro ripetitivo.

Save Your PUB Files aiuta quando Publisher è già installato e vuoi convertire molti file PUB in PDF in un’unica operazione. È uno strumento Windows per la conversione in blocco, non un visualizzatore PUB autonomo.
