Microsoft Publisher Ends in 2026: What Should You Do With Your PUB Files?

Microsoft Publisher support ends on October 1, 2026. The files do not disappear, but future access becomes the issue.

Back to home

What changes on October 1, 2026

Microsoft has announced that Publisher support ends October 1, 2026. Existing .pub files will still be files on your computer, but the practical question is how easily you will be able to open, edit, print, or share them later.

Microsoft recommends converting existing Publisher files before retirement. For important documents, PDF is often the most useful preservation format because it is widely readable and easy to share.

What to do if you have only a few PUB files

If you have a small number of documents, open them in a working Microsoft Publisher installation and export or save them to PDF manually. This is simple enough for a few files and lets you review the results as you go.

What to do if you have a large archive

Dozens, hundreds, or thousands of Publisher files are different. Opening each file and saving it manually can turn into a long cleanup project. For many files, Microsoft suggests considering automation with a PowerShell script.

That approach can work for technical users, but it is not comfortable for everyone. Save Your PUB Files is a practical alternative for nontechnical users who need to convert large Publisher archives through a normal Windows interface.

Publisher is still required

Save Your PUB Files does not replace Microsoft Publisher and does not open PUB files without Publisher. It uses the working Publisher installation on your Windows PC to perform the conversion while Publisher is still available.

If you are specifically looking for ways to view old files without Publisher, start with How to Open Publisher Files Without Microsoft Publisher.
