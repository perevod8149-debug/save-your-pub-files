Como abrir arquivos Publisher sem Microsoft Publisher

Sim, existem formas de abrir alguns arquivos Microsoft Publisher (.pub) sem Microsoft Publisher usando software de terceiros compatível, mas a compatibilidade e a formatação podem variar conforme o arquivo e o programa.

Importante: o que o Save Your PUB Files faz

Save Your PUB Files não permite abrir, visualizar nem editar arquivos PUB e não substitui o Microsoft Publisher. O Microsoft Publisher deve estar instalado e funcionando no PC com Windows.

O aplicativo foi criado para uma tarefa específica: converter dezenas ou centenas de arquivos Publisher em PDF de uma só vez, em vez de abrir e salvar cada arquivo um por um.

É possível abrir um arquivo PUB sem Publisher?

Às vezes, mas depende do arquivo e do que você quer dizer com abrir. Algumas ferramentas de terceiros podem importar ou pré-visualizar alguns arquivos Publisher, mas compatibilidade, precisão do layout, fontes, imagens e recursos de edição podem variar.

Se o documento for importante, não presuma que outro programa vai preservá-lo perfeitamente. Mantenha os arquivos PUB originais mesmo depois de criar cópias em PDF.

Se você só precisa abrir um ou dois arquivos PUB

Para poucos arquivos, primeiro verifique se ainda pode usar uma instalação funcional do Microsoft Publisher. Se não puder, talvez seja necessário testar uma suíte de escritório compatível, um serviço de conversão ou pedir a alguém com Publisher para exportar os arquivos para você.

Esse é um problema de acesso manual. Save Your PUB Files não foi feito para abrir um único arquivo PUB sem Publisher.

Se você precisa editar um arquivo PUB

Editar arquivos Publisher é o caso mais difícil. O caminho mais seguro ainda é o Microsoft Publisher, porque o formato do arquivo, o layout, as fontes, as imagens e as caixas de texto foram criados para o Publisher.

Se você editar um arquivo PUB em outra ferramenta, revise o resultado com cuidado antes de confiar nele.

Por que manter arquivos Publisher como cópias em PDF?

Para manter uma cópia visualizável, o PDF costuma ser prático porque é mais fácil de abrir, imprimir, compartilhar e manter acessível em computadores onde o Publisher não está disponível.

Não exclua seus arquivos PUB originais depois de convertê-los.

Um PDF preserva uma versão visualizável da publicação, mas não substitui o arquivo fonte editável do Publisher.

O que fazer antes do fim do suporte ao Publisher?

Se você ainda tem o Publisher instalado, converter seus documentos Publisher para PDF enquanto ele ainda funciona pode reduzir o risco de perder acesso depois. Para mais contexto, leia o que fazer com arquivos Publisher antes do fim do suporte ao Publisher.

  • Faça backup dos arquivos PUB originais.
  • Identifique arquivos que ainda podem precisar de edição no futuro.
  • Crie cópias em PDF dos documentos usados principalmente para visualização, impressão, compartilhamento ou consulta.
  • Verifique uma amostra dos PDFs convertidos.
  • Mantenha tanto os arquivos PUB originais quanto as cópias em PDF.

Tem muitos arquivos Publisher? É outro problema

Encontrar uma forma de abrir um arquivo PUB não é o mesmo que preservar uma pasta com dezenas ou centenas de documentos Publisher antigos. Quando há muitos arquivos, o trabalho repetitivo vira o problema.

Save Your PUB Files ajuda quando o Publisher já está instalado e você quer converter muitos arquivos PUB em PDF em uma só operação. É uma ferramenta Windows de conversão em lote, não um visualizador PUB independente.
