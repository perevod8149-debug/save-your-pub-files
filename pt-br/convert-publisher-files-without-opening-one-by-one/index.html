O fluxo manual

Para um arquivo, o caminho é simples:

Abrir arquivo PUB -> exportar ou salvar como PDF -> fechar o arquivo -> repetir

Se você quer converter todos os seus arquivos Publisher para PDF, esse processo fica demorado e fácil de interromper.

O fluxo com Save Your PUB Files

Save Your PUB Files reduz isso para:

Selecionar arquivos -> escolher a saída -> converter

Assim você pode converter vários arquivos Publisher de uma só vez, sem abrir cada arquivo manualmente. Os documentos ficam no seu PC Windows.

O que conversão automática significa aqui

O aplicativo não lê arquivos Publisher sem o Publisher. É necessária uma instalação funcional do Microsoft Publisher. Ele automatiza a exportação para os arquivos que o Publisher consegue abrir.

É útil com 20, 200 ou 2,000 arquivos.

FAQ

Posso converter arquivos PUB sem abrir cada um?

Sim. Você seleciona os arquivos e converte tudo de uma só vez.

Posso converter todos os meus arquivos PUB de uma só vez?

Sim, se o Microsoft Publisher estiver instalado e conseguir abrir esses arquivos.

Preciso abrir cada arquivo PUB individualmente?

Não. O aplicativo existe justamente para evitar esse trabalho repetitivo.
