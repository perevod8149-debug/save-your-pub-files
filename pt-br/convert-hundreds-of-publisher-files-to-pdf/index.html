Quando converter um por um deixa de fazer sentido

Com 2 ou 3 arquivos Publisher, exportar manualmente pode resolver. Com 20 arquivos, já fica repetitivo. Com 200 arquivos, você pode perder uma tarde inteira. Com 2,000 arquivos, vira um projeto grande.

Save Your PUB Files foi feito para usuários comuns do Windows que querem converter muitos arquivos Publisher para PDF sem scripts, sem PowerShell e sem linha de comando.

Converter vários arquivos de uma só vez

Você seleciona os arquivos PUB ou uma pasta inteira, escolhe onde salvar os PDFs e inicia a conversão. Save Your PUB Files usa o Microsoft Publisher instalado no seu PC Windows para criar as cópias em PDF.

Funciona para 20 arquivos, 200 arquivos ou uma pasta grande com 2,000 arquivos Publisher, desde que o Publisher consiga abrir esses documentos.

Para usuários de Windows, não para desenvolvedores

O aplicativo não substitui o Microsoft Publisher e não abre arquivos PUB sem o Publisher. Ele evita o trabalho repetitivo de abrir, exportar, fechar e começar tudo de novo.
