Por que PowerShell aparece

Para muitos arquivos Publisher, a Microsoft recomenda considerar automação com PowerShell. Muita gente prefere evitar scripts e terminal.

Uma interface comum do Windows

Save Your PUB Files usa um fluxo simples: escolher pasta, escanear, converter. Assim você converte uma pasta inteira e vários arquivos de uma só vez.

O que continua necessário

O Microsoft Publisher precisa estar instalado e funcionando no Windows. O app não abre arquivos PUB sem Publisher, e o processamento é local.
